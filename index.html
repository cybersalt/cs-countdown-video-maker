Using the files in your editor

Put the countdown on a track above your footage so the transparent parts show the video underneath. Pick your editor:

VEGAS Pro
  1. Export as PNG sequence. VEGAS Pro 23 dropped Apple's QuickTime plugin, so it can't read the transparent MOV (you only get the sound).
  2. File → Import → Media, open the exported folder, select frame_00000.png and tick Open still image sequence. The whole countdown comes in as one clip.
  3. Drag it onto a video track above your footage. If the background shows black instead of see-through: right-click the clip → Properties → Media tab → Alpha channel → Straight (unmatted).
  4. In the same Media tab, check the frame rate is 30 so the clip stays in sync with the sound.
  5. Add audio.wav from the same folder to an audio track, starting at the same point as the clip.
  6. Older VEGAS (22 and earlier, with QuickTime enabled under Preferences → Deprecated Features) can use the .mov directly.
Camtasia
  1. Import Media (Ctrl+I) and choose the .mov. It appears in the Media Bin.
  2. Drag it onto a track above your footage. The transparency is kept automatically.
  3. Use the MOV rather than the PNG sequence. Camtasia handles MOV files with the PNG codec, which is what this exports.
  4. To move or resize the timer, drag it on the canvas. It's a normal 1920×1080 clip.
DaVinci Resolve
  1. Import the .mov into the Media Pool (drag it in, or File → Import → Media).
  2. Drop it on V2 (or higher) above your footage on V1.
  3. If the background isn't see-through: right-click the clip in the Media Pool → Clip Attributes → Video → Alpha Mode → Straight.
  4. PNG sequence: import the folder. Resolve shows the numbered frames as one clip. Add audio.wav on an audio track.
Adobe Premiere Pro
  1. File → Import the .mov and place it on V2 above your footage.
  2. Transparency is usually picked up automatically. If not: right-click the clip in the Project panel → Modify → Interpret Footage → make sure Ignore Alpha Channel is off.
  3. PNG sequence: File → Import, select the first frame and tick Image Sequence.
OBS Studio (live streams)
  1. In your scene, add a Media Source and choose the .mov. It plays with transparency over your other sources.
  2. Tick Restart playback when source becomes active so it starts from the top each time you show it.
  3. Drag the source to position or resize it.
Other editors
  1. Try the .mov first. Most editors read QuickTime with the PNG codec and keep the transparency.
  2. If yours doesn't, use the PNG sequence (almost every editor can import numbered image sequences) plus audio.wav.
  3. If you don't need transparency, the MP4 works everywhere. Or export on green and use the editor's chroma key.
